# learnweb

静态学习网站仓库。三个独立分支分别存放三个站点，每个分支的根目录即为站点根目录（含 index.html），可直接用于静态网站托管平台部署。

## 分支说明

| 分支 | 站点 | 文件数 | 部署地址分支 |
|------|------|--------|--------------|
| `js` | JavaScript 系统学习 · 课程笔记精编 | 60 | js |
| `vue3` | Vue 3 系统学习 · 课程笔记精编 | 26 | vue3 |
| `java` | Java 学习手册 · 从零到项目实战 | 17 | java |

## 帽子云静态网站部署配置

为每个站点创建一个静态网站应用，配置如下：

- **代码仓库**：lwwtutu/learnweb
- **分支**：分别选择 `js` / `vue3` / `java`
- **根目录**：留空（默认仓库根目录）
- **构建命令**：留空（纯静态站点，无需构建）
- **输出目录**：留空（默认根目录）

三个站点互不依赖，可独立部署与更新。
