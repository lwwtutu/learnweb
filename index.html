把 Java 学成
真正会用的样子

不是把语法背一遍，而是按「知识点 → 可运行代码 → 易错点 → 自测」的节奏推进。每章都有完整示例，学完就能写出能跑的程序。

从第 1 章开始 浏览全部章节 建议每天 1–2 章，两周走完
HelloJava.java java 
public class HelloJava {
    public static void main(String[] args) {
        // 从第一个程序，一步步走到项目实战
        String[] roadmap = {
            "语法地基", "数组与字符串",
            "面向对象", "项目实战"
        };

        for (int i = 0; i < roadmap.length; i++) {
            System.out.println((i + 1) + ". " + roadmap[i]);
        }
    }
}

怎么学才有效

三条被反复验证过的建议，能帮你少走至少一半的弯路。

✎

代码一定要自己敲

看懂和写出来是两件事。每个示例都在本地跑一遍，改几个值观察输出变化，比读十遍笔记更有效。

◎

先跑通，再追问为什么

遇到报错先读异常栈：异常类型在前、出错行号在后。搞不清就回到本章「易错点」，90% 的坑都写过。

✓

用项目检验掌握程度

每学完一段，试着不看答案复写小项目：成绩管理、图书查询、石头迷阵。能独立完成才算真的会。
